📖 Mode d'Emploi & Documentation Technique

1. Présentation

CYTOsecours est un outil fonctionnant localement (hors réseau internet) destiné aux pharmaciens spécialistes en production des chimiothérapies, comme outil d'assistance en cas de défaut du logiciel standard d'aide à la préparation (p.ex CATO). Il permet d'automatiser les calculs de doses, les volumes à préparer, et d'importer des constantes comme les étapes de préparation et enfin d'exporter ces données sous forme de fiches de préparation structurées compréhensibles par des pharmaciens et des préparateurs. La validation des données finales reste sous la responsabilité du pharmacien valideur, qui doit vérifier la cohérence des données avant de générer la fiche finale.

2. Bases de données & dépendances entre elles

  • CYTOsecours possède 4 bases de données : une pour les thérapies, une pour les procédures et le matériel, une pour les diluants, et une pour les unités de prescription.
  • Les bases des thérapies et des procédures sont reliées entre elles par une clé constituée par le dispositif d'administration, si une reconstitution est nécessaire (True/False) et le type de remplissage (AD, POUR, BOLUS). Exemple de clé : "Poche remplieTrueAD".
  • Ainsi toute thérapie présente dans la base de données doit générer une clé valide et reconnue par la base de données des procédures.
  • Toutes les thérapies partageant la même clé ont la même procédure et le même matériel associé.

3. Utiliser CYTOsecours

  1. Remplir la section "Patient". Les données de poids (en kg) et de taille (en cm) sont obligatoires pour calculer la surface corporelle (Mosteller).
  2. Remplir la partie prescription en renseignant tous les champs. Le coefficient (par défaut = 1.0) permet d'ajuster la dose calculée lorsque le prescripteur a par exemple indiqué "90% de la dose" (dans ce cas le coefficient = 0.9). NB : si "AUC" est sélectionné comme unités de prescription, alors une fenêtre dédiée au calcul de la dose en mg selon AUC Calvert s'ouvre. La valeur calculée en mg sera alors importée dans le champ "dose calculée".
  3. Une fois les données Patient et Prescription saisies, la section Préparation applique les calculs nécessaires pour déterminer les éléments nécessaires à la réalisation d'une fiche de production. Les valeurs doivent être vérifiées. Cette section permet également de visulaiser les étapes de préparation, le matériel qui sera nécessaire aux préparateurs, ainsi que les remarques éventuelles adressées aux préparateurs.
  4. La section Validation permet au pharmacien d'ajouter une note pour le prépateur (sera reportée sur la fiche de production), de statuer sur le statut de la préparation et enfin d'exporter le rapport final (un fichier PDF contenant la fiche de préparation destinée au préparateur, une feuille avec 4 étiquettes pour le produit final ainsi qu'une fiche résumant toutes les valeurs saisies et tous les calculs). Le visa du pharmacien est obligatoire pour générer la fiche PDF.

4. Utiliser Gestion des données

  • Ce volet permet de visualiser et de modifier les 4 bases de données de l'application. Les modifications ne sont possibles que par importation de fichier (pas d'interface de création, suppression ou modification directement dans l'application). Les fichiers importés doivent être au format XLSX ou JSON et respecter la structure des bases de données natives, pour cela il est recommandé d'exporter les bases actuelles pour les sauvegarder et les modifier si besoin, sans modifier la structure ni les entêtes puis d'importer le fichier modifié.
  • Le bouton "Réinitialiser aux données natives" permet de restaurer les bases de données initiales de l'application, en cas de problème avec les fichiers importés.
  • L'outil "Importer et remplacer une base" permet de sélectionner la base à remplacer et d'importer un fichier structuré. Les bases importées sont stockées localement dans le navigateur et seront utilisées par l'application jusqu'à ce qu'elles soient remplacées ou réinitialisées. UN IMPORT DE FICHIER NE REMPLACE PAS LES DONNÉES DANS LE CODE DU FICHIER (le même fichier copié et installé sur un autre ordinateur s'ouvrira avec ses bases de données initiales).

5. Glossaire

  • "Dispositif" (ou Dispositif d'administration): Contenant final dans lequel le produit sera préparé (poche, seringue, flacon, etc.)
  • "Type de remplissage" : Méthode de remplissage du dispositif.AD (jusqu'à un volume défini), POUR (volume de produit ajouté au volume du dispositif), BOLUS (sans ajout de soluté de dilution, "pur").
